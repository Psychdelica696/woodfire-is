# ADR-001. Трирівнева клієнт-серверна архітектура

**Статус:** accepted (13.10.2026)

**Контекст.** Одна піцерія, три клієнтські застосунки зі спільними даними; обов'язкова фіскалізація, онлайн-оплата, офлайн-режим каси; малий бюджет і команда 1–3 розробники.

**Розглянуті варіанти.** 2-tier; 3-tier + модульний моноліт N-layer + Ports & Adapters; мікросервіси; Event-Driven.

**Рішення.** Клієнти → REST API (NestJS) → PostgreSQL. Сервер поділено на рівні Presentation, Application, Domain, Infrastructure (послаблена ізоляція). Інтеграції — через порти IFiscalGateway, IPaymentGateway, INotifier та адаптери.

**Наслідки.** Простий супровід і тестування бізнес-логіки, одне розгортання; масштабування лише застосунку цілком.
