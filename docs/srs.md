# Специфікація вимог (SRS) — стислий виклад (л.р. №2)

## Класи користувачів
Клієнт, касир-оператор, власник піцерії.

## Системні функції
| Код | Вимога |
|---|---|
| FR-1.1 | Додавання, зміна кількості та видалення позицій у кошику |
| FR-1.2 | Автоматичний перерахунок суми з урахуванням модифікаторів і знижок |
| FR-1.3 | Позначення страви недоступною за відсутності інгредієнта |
| FR-2.1 | Облік залишків інгредієнтів (кг, л, шт.) |
| FR-2.2 | Сповіщення власника при досягненні мінімального залишку |
| FR-2.3 | Ручне коригування залишків при постачанні |
| FR-3.1 | Оплата готівкою, карткою, QR-кодом |
| FR-3.2 | Фіскальний чек для кожної оплати |
| FR-3.3 | Черга чеків при відсутності зв'язку з РРО |
| FR-4.1 | Звіт про продажі за період |
| FR-4.2 | Розрахунок собівартості страви |
| FR-4.3 | Експорт звітів у PDF / Excel |

## Нефункціональні вимоги
Чек ≤ 2 с; до 50 активних замовлень; меню ≤ 3 с; доступність ≥ 99 %; ролі та автентифікація; PCI DSS для платежів.
