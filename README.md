# WoodFire — інформаційна система піцерії з дров'яною піччю

Навчальний проєкт з дисципліни «Технології розроблення програмних систем» (КНУ ім. Тараса Шевченка, ФІТ, група ПП-42).

## Призначення
Автоматизація роботи невеликої піцерії: приймання замовлень (каса та онлайн), облік складу інгредієнтів, оплата з фіскалізацією, програма лояльності, звіти для власника.

## Функціональність
- оформлення замовлень (на місці, на винос, доставка) з модифікаторами та знижками (FR-1.1 – FR-1.3);
- облік залишків і автоматичне списання інгредієнтів за рецептурою (FR-2.1 – FR-2.3);
- оплата готівкою, карткою, QR-кодом і фіскалізація через ПРРО (FR-3.1 – FR-3.3);
- програма лояльності (нарахування та списання бонусів);
- звіти про продажі, собівартість і рентабельність (FR-4.1 – FR-4.3).

## Технології
| Частина | Технології |
|---|---|
| Бізнес-логіка (поточна ітерація) | JavaScript (Node.js 20+, ES-модулі), тести `node:test` |
| Backend (цільова архітектура, ADR-001) | Node.js · NestJS, PostgreSQL, Redis (черга задач) |
| Клієнтський застосунок і панель керівника | React + TypeScript (PWA / SPA) |
| POS-застосунок | Android · Kotlin · MVVM · Room |
| Інтеграції | ПРРО (Checkbox API), платіжний шлюз (LiqPay), FCM / SMS / Email |
| CI | GitHub Actions |

## Запуск
Потрібен Node.js 20 або новіший; сторонні залежності не використовуються.
```bash
git clone https://github.com/<логін>/woodfire-is.git
cd woodfire-is
npm test          # запуск автоматизованих тестів
npm run check     # перевірка структури репозиторію
```
